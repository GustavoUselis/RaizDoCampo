 # Raiz do Campo
Conectando quem produz com quem vende.

O Raiz do Campo é uma plataforma criada com o objetivo de conectar agricultores locais aos mercados da região, facilitando a comercialização de produtos agrícolas e fortalecendo a economia local.

A proposta é aproximar diretamente quem produz de quem precisa comprar, criando uma rede de comércio mais simples, acessível e sustentável.

# Objetivo

O projeto busca contribuir para o desenvolvimento da agricultura local por meio da tecnologia, criando um canal de comunicação entre:

 - Agricultores e produtores rurais;
 - Mercados e estabelecimentos da região;
 - Comerciantes interessados em produtos locais.

Dessa forma, o RaizDoCampo pretende facilitar a oferta e a procura de produtos agrícolas, 
reduzindo dificuldades na comercialização e aumentando as oportunidades para os produtores.

# Agricultura Circular

Um dos principais conceitos do projeto é a agricultura circular.

A ideia é criar um ciclo em que os recursos e produtos da própria região sejam movimentados dentro da comunidade, 
fortalecendo os produtores locais e reduzindo a dependência de grandes cadeias de distribuição.

Produtor → RaizDoCampo → entities.Mercado → Consumidor → Economia local

Ao aproximar produtores e mercados, o projeto busca fazer com que uma parcela maior do valor gerado pela produção permaneça na própria região.

# Como funciona :

O Raiz do Campo funciona como uma ponte entre agricultores e mercados.

# Para o agricultor

O produtor poderá:

* Cadastrar seus produtos;
* Informar quantidade disponível;
* Definir preços;
* Apresentar sua produção aos mercados da região;
* Encontrar novos compradores;
* Ter maior visibilidade para sua produção.

# Para os mercados

Os estabelecimentos poderão:

* Encontrar produtores da região;
* Visualizar produtos disponíveis;
* Consultar preços e quantidades;
* Entrar em contato com agricultores;
* Facilitar a compra de produtos locais.

# Impacto esperado

O projeto busca gerar benefícios tanto para os produtores quanto para os estabelecimentos locais.

# Para os agricultores:

* Maior acesso ao mercado;
* Novas oportunidades de venda;
* Maior visibilidade;
* Fortalecimento da produção local.

# Para os mercados:

* Facilidade para encontrar fornecedores;
* Acesso a produtos produzidos na região;
* Possibilidade de diversificar seus fornecedores;
* Aproximação com produtores locais.

# Para a região:

* Fortalecimento da economia local;
* Incentivo à agricultura;
* Maior circulação de recursos dentro da comunidade;
* Aproximação entre campo e comércio.
  
# Proposta do projeto

O Raiz do Campo não pretende apenas criar uma plataforma de compra e venda.
A proposta é utilizar a tecnologia para fortalecer uma rede local, 
aproximando o campo dos mercados e incentivando um modelo de comercialização mais conectado com a realidade dos produtores da região.
Do campo para o mercado. Do mercado para a comunidade.
